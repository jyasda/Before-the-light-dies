# Before-the-light-dies
A tense first-person survival horror game where you manage your flashlight battery to survive. Running out triggers a countdown, don't let it reach 0. Scavenge for glowing batteries and reach the final door to escape. Its always watching... To play any version of the game (best is the most recent version), go to https://github.com/jyasda/Before-the-light-dies/releases , then download, extract, and click the "BeforeTheLightDies.exe" file. You can also find the latest version of the game at https://scta.itch.io/beforethelightdies .To access the project files, go use the same link to go to releases, and find the Project file release (I had to put it in releases becasue the file was too big and it would not let me upload it normally). Download and extract those files and then you will be able to put those files in Unity or see the assets and scripts I used in this game. Enjoy!

Version 1: In this version, I completed the main portion of the game, yet it still lacks a ending and the player cannot currently beat the game, however; all the visuals have been polished with minor tweaks in the future. This build of the game also features a working "monster", so the player can die, but there is still work to be done. The flashlight feature is also made but future tweaks may come. Major updates for the next build: A ending, monster tweaks, and many bug fixes.

Version 2: For this version, I added what the game lacked, a ending, credits, and a Main Menu. Now the game is fully complete and playable, yet future bug and visual tweaks may come.
